# Vibeling Tutor

Русский · [English](README.en.md)

Репетитор иностранного языка внутри [Claude Code](https://claude.com/claude-code).
Claude составляет план уроков, проводит их в чате — объяснение, примеры, задания с
проверкой — и сохраняет выученные слова в ваш словарь
[Vibeling](https://vibeling.app), где их можно тренировать в приложении.

Готовый пример — английский с нуля (`lessons/en/plan.md`), но язык, уровень и
язык объяснений настраиваются.

Репозиторий рассчитан на Claude Code, но словарь Vibeling подключается и к другим
ИИ-ассистентам с поддержкой MCP: ChatGPT, Claude (claude.ai и приложения), Codex,
Cursor и VS Code — см. [Другие инструменты](#другие-инструменты).

## Установка

Нужен установленный Claude Code.

```bash
git clone https://github.com/pavlenkovit/vibeling-tutor.git
cd vibeling-tutor
claude
```

При первом запуске Claude Code спросит, подключать ли MCP-сервер `vibeling` из
`.mcp.json`, — согласитесь.

## Подключение Vibeling

Уроки работают и без этого шага; он нужен, чтобы сохранять слова в словарь.

1. В Claude Code наберите `/mcp`, выберите `vibeling` → Authenticate.
2. Откроется страница входа Vibeling. Введите код привязки из приложения:
   Профиль → Настройки → Мои устройства → «Подключить новое устройство».
   Приложения нет — нажмите «Создать новый аккаунт»; открыть его в приложении
   потом поможет сам Claude («дай код для приложения»).
3. Сохранение слов требует подписки Vibeling PRO.

## Как заниматься

| команда | что делает |
|---|---|
| `/setup` | выбрать язык, уровень, язык объяснений, цель; проверить Vibeling |
| `/plan-lessons` | составить план уроков под ваш язык и уровень |
| `/lesson` | пройти следующий урок; `/lesson 7` — конкретный |
| `/save-words` | сохранить слова в Vibeling (после урока предлагается само) |

Можно и словами: «давай заниматься», «хочу учить испанский с нуля», «повтори урок 3».

Настройки лежат в `profile.md`, план — в `lessons/<язык>/plan.md`, ваш прогресс —
в `progress.md` (в git не попадает).

## Другие инструменты

MCP-сервер Vibeling — `https://mcp.vibeling.app` — работает в любом клиенте с
поддержкой MCP. Вход везде одинаковый: код привязки из приложения или «Создать
новый аккаунт» на странице Vibeling.

| клиент | как подключить |
|---|---|
| ChatGPT | Настройки → Приложения (или «Коннекторы») → Дополнительные настройки → режим разработчика; «Создать», имя Vibeling, адрес сервера, авторизация OAuth. В чате — включить через «+». Режим разработчика есть не на всех тарифах |
| Claude (claude.ai) | Настройки → Коннекторы → «Добавить свой коннектор», имя Vibeling, адрес сервера → «Добавить» → «Подключить». Появится и в приложениях Claude |
| Codex | `codex mcp add vibeling --url https://mcp.vibeling.app`, затем `codex mcp login vibeling` |
| Cursor, VS Code | кнопки «Добавить в Cursor» / «Добавить в VS Code» на странице инструкции |

Подробно — [vibeling.app/ru/ai-agents](https://vibeling.app/ru/ai-agents).

Скилы (`/setup`, `/lesson` и другие) — формат Claude Code. В других инструментах
их можно использовать как обычные инструкции: попросите ассистента прочитать
`CLAUDE.md` и нужный `.claude/skills/<скил>/SKILL.md` и действовать по ним, или
вставьте текст скила в инструкции проекта (например, в ChatGPT или Claude Projects).

## Устройство

```
CLAUDE.md                 роль репетитора и правила урока
profile.md                ваши настройки
lessons/<язык>/plan.md    план уроков
.claude/skills/           setup, plan-lessons, lesson, save-words
.mcp.json                 MCP-сервер Vibeling (https://mcp.vibeling.app)
```
